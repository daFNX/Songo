# Contribuir a Songo

Gracias por ayudar a construir Songo. Mantengamos los cambios claros y fáciles de revisar.

## Mensajes de commit

Escribe los commits en español, con un prefijo breve y una explicación directa:

```text
feat: añade grabación desde el micrófono
fix: corrige el límite de duración del audio
docs: explica cómo ejecutar las pruebas
```

Usa `feat`, `fix`, `docs`, `test`, `refactor` o `chore` según el cambio. Resume el resultado en una sola línea, sin punto final. Añade una descripción adicional solo si hace falta explicar una decisión importante.

## Cambios

- Mantén cada cambio enfocado y fácil de probar.
- Ejecuta las pruebas relacionadas y `npm run build` antes de enviar cambios.
- No incluyas credenciales, archivos de audio privados ni datos personales.
- No actives funciones que todavía no estén implementadas y verificadas.
